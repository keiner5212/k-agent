System reminder

Same system string, pasted onto a later user turn. It is not a second prompt and it is not stored in the session file. The plain write-up is reminder.md.

How it is built

  1. Build the system string for this send: language rule, AGENTS.md, then the tagged agent sections.
  2. Read reminderInterval. Default 8. Values 1 through 500. Empty system text or interval 0 skips the reminder.
  3. Count user turns that are not tool results.
  4. When the count is a positive multiple of the interval, append <system-reminder> to that last user turn.

Source: applySystemReminder in src/lib/session-turns.ts.

Example, interval 4, fourth user turn

user turn the message the user typed 
Please check the sidebar filter.
system-reminder full system string, appended after a blank line 
<system-reminder>
<language>
LANGUAGE RULE - VERY IMPORTANT
You must reply ONLY in English.
</language>

<personality>
You are the build agent. Be concise.
</personality>

...the rest of the same system string...
</system-reminder>

The example is cut. A real reminder pastes the whole system string, and personality is already in it. A loaded skill stays in the chat as its tool result. The next reminder lands on user turn 8, then 12.
